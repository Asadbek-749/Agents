2. Dars maqsadi

Dars oxirida óquvçi:

  1. Yangi hujjatni kerakli papkaga, tuşunarli nom bilan saqlay oladi (Save As yoki F12).
  2. Save va Save As farqini tuşuntiradi, hujjatni boşqa nom yoki PDF formatda nusxa qilib saqlay oladi.
  3. Avtomatik saqlaşni (AutoRecover) yoqadi va saqlanmay qolgan hujjatni tiklay oladi.

3. Kerakli narsalar

  • Microsoft Word 2016, 2019, 2021 yoki Microsoft 365 (ingliz yoki rus interfeysi).
  • Har bir kompyuterda «Documents» («Документы») papkasi.
  • Óqituvçi kompyuteri va proyektor.
  • Internet şart emas. Faqat OneDrive haqida gapirilsa kerak bóladi.

5. Qadamma-qadam kórsatma

AtamaSodda tuşuntiriş

Saqlaş (Save)Hujjatni kompyuter xotirasiga yozib qóyiş. Saqlanmagan matn doskaga bór bilan yozilgan yozuvga óxşaydi: óçirilsa, yóqoladi.

AutoRecoverWord har bir neça daqiqada yaşirin zaxira nusxa olib turadi. Bu svet óçganda yordam beradi, lekin oddiy saqlaşning órnini bosmaydi.

1Birinçi marta saqlaş (Save As)

Qayerni bosiş: File (Файл) → Save As (Сохранить как) → Browse (Обзор). Tezroq yól: klaviaturada F12.

Nima çiqadi: «Save As» oynasi oçiladi: çapda papkalar, pastda «File name» (Имя файла) va «Save as type» (Тип файла) qatorlari.

Keng tarqalgan xato: Óquvçi papkani tanlamasdan Save bosadi va fayl qayerga ketganini bilmaydi.

Tuzatiş: Avval oynaning çap tomonidan «Documents» yoki «Desktop» ni tanlang, keyin saqlang. Fayl yóqolgan bólsa: File → Open → Recent (Последние) da topiladi.

2Papka tanlaş va yangi papka oçiş

Qayerni bosiş: Save As oynasida kerakli joyni tanlang → yuqoridagi «New folder» (Новая папка) → nom yozing, masalan «Word darslari» → Enter → papkani ikki marta bosib içiga kiring.

Nima çiqadi: Yangi papka róyxatda paydo bóladi, oyna yuqorisidagi manzil qatorida uning nomi kórinadi.

Keng tarqalgan xato: Papka yaratiladi, lekin içiga kirilmaydi. Fayl papkaning taşqarisida saqlanadi.

Tuzatiş: Save bosişdan oldin yuqoridagi manzil qatorida papka nomi turganini tekşiring.

3Faylga tóǵri nom beriş

Qayerni bosiş: «File name» (Имя файла) qatoriga nom yozing. Nom mazmunni aytsin va sanasi bólsin: Ariza_Karimov_2026-11-21. «Document1», «Yangi», «111» kabi nomlar yomon.

Nima çiqadi: Saqlangandan keyin Word oynasining eng yuqorisida yangi nom kórinadi.

Keng tarqalgan xato: Nomga \ / : * ? " < > | belgilari yoziladi yoki «.docx» qólda yozilib, kengaytma buziladi.

Tuzatiş: Bu belgilar órniga pastki çiziq (_) yoki tire (-) işlating. Kengaytmani yozmang: Word uni ózi qóşadi, format «Save as type» róyxatida tanlanadi.

4Keyingi saqlaşlar: Save (Ctrl+S)

Qayerni bosiş: Hujjatni ózgartirgaç Ctrl+S ni bosing yoki yuqori çap burçakdagi disket belgisini bosing.

Nima çiqadi: Heç qanday oyna çiqmaydi. Word faylni şu nom va şu joyda yangilaydi.

Keng tarqalgan xato: Óquvçi har safar Save As bosib, «Ariza1», «Ariza2», «Ariza3» kabi keraksiz nusxalar yaratadi.

Tuzatiş: Qoida: birinçi marta Save As, keyin faqat Ctrl+S. Har 5–10 daqiqada Ctrl+S bosiş odat bólsin.

5Nusxa yoki PDF formatda saqlaş

Qayerni bosiş: File → Save As → Browse → «Save as type» (Тип файла) róyxatidan PDF ni tanlang → Save.

Nima çiqadi: Papkada ikki fayl bóladi: Ariza.docx (tahrirlaş uçun) va Ariza.pdf (yuboriş va çop etiş uçun).

Keng tarqalgan xato: PDF yaratilgaç, asl .docx faylni keraksiz deb óçirib yuboradi.

Tuzatiş: .docx asl nusxa, uni doim saqlang. PDF faqat yuboriş uçun: uni Word'da qulay tahrirlab bólmaydi.

Asosiy formatlar

FormatQaçon işlatiladi
.docxOddiy Word hujjati. Tahrirlaş uçun asosiy format.
.pdfÓqiş, yuboriş va çop etiş uçun. Hamma qurilmada bir xil kórinadi.
.docEski Word (2003 va undan oldingi) uçun. Faqat juda eski kompyuterga yuborilsa.
.dotxŞablon: bir xil hujjatlarni (ariza, buyruq) tez yaratiş uçun.

6Avtomatik saqlaşni yoqiş (AutoRecover)

Qayerni bosiş: File → Options (Параметры) → Save (Сохранение) → «Save AutoRecover information every» belgisini qóying, raqamni 10 dan 5 ga ózgartiring → OK.

Nima çiqadi: Endi Word har 5 daqiqada yaşirin zaxira nusxa oladi.

Keng tarqalgan xato: AutoRecover yoqilgaç, óquvçi Ctrl+S bosmay qóyadi.

Tuzatiş: AutoRecover faqat favqulodda holat (svet óçişi, kompyuter qotişi) uçun. Asosiy saqlaş baribir Ctrl+S.

7Saqlanmagan hujjatni tiklaş

Qayerni bosiş: Word'ni qayta oçing: çapda «Document Recovery» paneli çiqadi. Çiqmasa: File → Info (Сведения) → Manage Document (Управление документом) → Recover Unsaved Documents (Восстановить несохраненные документы).

Nima çiqadi: Saqlanmay qolgan fayllar róyxati oçiladi.

Keng tarqalgan xato: Tiklangan faylni oçib, saqlamasdan yopadi va u yana yóqoladi.

Tuzatiş: Tiklangan faylni darhol Save As bilan óz papkangizga saqlang.

8Word yopilayotganda çiqadigan savol

Qayerni bosiş: Word'ni yopganingizda sóraydi: «Want to save your changes?». Tugmalar: Save / Don't Save / Cancel (Сохранить / Не сохранять / Отмена).

Nima çiqadi: Save bossangiz saqlanadi, Don't Save bossangiz oxirgi ózgarişlar yóqoladi, Cancel oynaga qaytaradi.

Keng tarqalgan xato: Şoşilib «Don't Save» bosiladi.

Tuzatiş: Ikkilansangiz Save yoki Cancel ni bosing. «Don't Save» ni faqat ózgarişlar kerak bólmasa bosing.

6. Amaliy topşiriq

Vaziyat: siz idorada yoki óz dókoningizda işlaysiz va rahbarga ariza yozişingiz kerak. Ariza yóqolmasligi, tez topilişi va elektron poçta orqali yuborilişi kerak.

Oson

  1. Yangi hujjatga 3 qatorli ariza yozing: kimga, kimdan, nima sóraysiz.
  2. «Documents» içida «Word darslari» papkasini yarating.
  3. Arizani F12 orqali «Ariza_Familiyangiz» nomi bilan şu papkaga saqlang.

Órta

  1. Arizaga sana va imzo qatorini qóşing, Ctrl+S bilan saqlang.
  2. Şu arizani PDF formatda ham saqlang. Papkada 2 ta fayl bólsin: .docx va .pdf.

Murakkab

  1. AutoRecover vaqtini 5 daqiqaga sozlang.
  2. «Word darslari» içida «Arizalar» va «Hisobotlar» papkalarini yarating.
  3. Arizani Save As bilan «Arizalar» papkasiga «Ariza_Familiya_2026-11-21» nomi bilan saqlang.
  4. Yangi hujjat oçib, 1 gap yozing va Word'ni yopişga urining. Çiqqan oynada tóǵri tugmani tanlab, hujjatni «Hisobotlar» papkasiga saqlang.

7. Tekşiriş savollari

1. Save va Save As farqi nima?

Javob: Save faylni şu nom va şu joyda yangilaydi. Save As yangi nom, joy yoki formatda nusxa yaratadi; birinçi marta saqlaşda ham Save As işlaydi.

2. Save As oynasini qaysi tugma bilan tez oçiş mumkin?

Javob: F12.

3. Nima uçun «Document1» yomon fayl nomi?

Javob: U hujjat mazmunini aytmaydi, keyin faylni topiş qiyin bóladi, bir xil nomlar kópayib ketadi.

4. Hujjatni hamma joyda bir xil kórinadigan qilib yuboriş uçun qaysi formatda saqlaysiz?

Javob: PDF.

5. Svet óçib, hujjat saqlanmay qolsa nima qilasiz?

Javob: Word'ni qayta oçib Document Recovery paneliga qarayman yoki File → Info → Manage Document → Recover Unsaved Documents ni bosaman. Topilgan faylni darhol Save As qilaman.

8. Uyga vazifa

Óz işingiz yoki óqişingiz uçun 1 ta haqiqiy hujjat yozing (ariza, tuşuntiriş xati, narxlar róyxati). «Documents» içida tartibli papka yarating (masalan: Iş → Arizalar). Faylni qoidaga mos nom bilan .docx va .pdf formatda saqlang. Papka oçiq turgan ekranning rasmini (Win + Shift + S) óqituvçiga yuboring.

9. Óqituvçi uçun eslatma

  • Eng kóp qiynaladigan joy: óquvçi Save As oynasida qaysi papkada turganini tuşunmaydi. Manzil qatorini proyektorda kattalaştirib kórsating.
  • Kattalar kópinçha hamma narsani Desktop'ga saqlaşga órganib qolgan. Tartibsiz Desktop rasmini kórsatib, «javon» misolini eslating.
  • Sinfda rus va ingliz interfeysli kompyuterlar aralaş bólsa, menyu nomlarini doskaga ikki tilda yozib qóying.
  • Word 2016 va keyingilarida Save As bosilganda avval kulrang sahifa çiqadi, Browse ni bosiş kerak. F12 esa oynani darhol oçadi: buni alohida taʼkidlang.
  • Microsoft 365 va OneDrive ulangan bólsa, yuqorida «AutoSave» (Автосохранение) tugmasi bor: u faylni bulutda real vaqtda saqlaydi. Qisqa aytib óting, lekin asosiy odat baribir Ctrl+S.
  • Qóşimça vaqt bólsa: Explorer'da fayl nomini F2 bilan ózgartiriş va View → File name extensions orqali kengaytmani kórsatişni órgating.
